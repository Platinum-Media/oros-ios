# OROS iOS SDK 1.0.0-preview.1

The OROS iOS SDK as a binary Swift package. In Xcode: File → Add Package Dependencies → this repository's URL, version 1.0.0-preview.1.
Then `import Oros`. The developer docs show the attach call.

The binary is https://sdk.oros.platinum.digital/ios/1.0.0-preview.1/Oros.xcframework.zip; Package.swift pins its checksum.
